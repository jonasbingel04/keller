# Keller App

Eine intuitive Flutter-App, um den Überblick über deine Vorräte im Gefrierschrank zu behalten.

##  Features

- **Kategorisierte Übersicht:** Schneller Zugriff auf Fleisch, Gemüse, Backwaren, Eis und mehr.
- **Echtzeit-Daten:** Dank Supabase-Integration sind deine Bestände sofort auf allen Geräten synchronisiert.
- **Bestandsverwaltung:**
  - Artikel mit Anzahl und Portionsgröße hinzufügen.
  - Mengen direkt in der Listenansicht erhöhen oder verringern.
  - Automatisches Löschen von Artikeln, wenn die Menge auf 0 sinkt.
- **Dark Mode Support:** Schont die Augen bei der nächtlichen Suche nach dem letzten Eis.

##  Tech Stack

- **Frontend:** [Flutter](https://flutter.dev/)
- **Backend:** [Supabase](https://supabase.com/) (PostgreSQL & Realtime Streams)
- **Konfiguration:** `flutter_dotenv` für sichere API-Keys.
- **Icons:** `community_material_icon` für eine große Auswahl an Lebensmittel-Symbolen.

##  Installation & Setup

### 1. Voraussetzungen
Stelle sicher, dass du das Flutter SDK installiert hast und ein aktives Supabase-Projekt besitzt.

### 2. Datenbank-Schema
Erstelle in deinem Supabase SQL-Editor die folgende Tabelle:

```sql
create table freezer (
  id bigint generated by default as identity primary key,
  item text not null,
  amount int8 not null default 0,
  portion_size text,
  category text,
  date date default now()
);
```

### 3. Umgebungsvariablen
Erstelle eine Datei namens `.env` im Hauptverzeichnis deines Projekts (diese Datei wird durch die `.gitignore` automatisch ignoriert):

```env
SUPABASE_URL=[https://deine-projekt-id.supabase.co](https://deine-projekt-id.supabase.co)
SUPABASE_ANON_KEY=dein-anon-key-hier
```
### 4. Abhängigkeiten installieren

Bevor du die App startest, musst du alle benötigten Pakete (wie `supabase_flutter` und `flutter_dotenv`) herunterladen. Öffne dazu dein Terminal im Projektordner und führe aus:

```bash
flutter pub get
```
### 5. App starten

Nachdem die Abhängigkeiten geladen sind, kannst du die App auf einem Emulator oder einem angeschlossenen echten Gerät starten:

```bash
flutter run
```

##  Projektstruktur

- `lib/main.dart`: Hauptmenü (Grid-Ansicht) und App-Konfiguration.
- `lib/addPage.dart`: Logik zum Hinzufügen neuer Artikel.
- `lib/categoryList.dart`: Dynamische Liste der Artikel mit Update/Delete-Funktionen.

##  Sicherheitshinweis

Dieses Projekt nutzt eine `.env` Datei, um sensible API-Schlüssel von der Versionskontrolle fernzuhalten. Stelle sicher, dass die `.env` Datei niemals auf öffentliche Repositories hochgeladen wird.
